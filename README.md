Entry for the make.fun bounty "Seventeen Syllables of Debugging"
($5 pool, blind judged rounds).

The haiku, 5-7-5 syllables:

> Null pointer at dawn —
> the bug I fixed last Tuesday
> it wears my old name.

Run it: `python3 main.py`

Alternate haikus tried in this session (kept as spares, one entry each):
1. "Stack trace in the dark — / the fix I shipped on Friday / failed Monday morning."
2. "Breakpoint at midnight — / the race condition laughs last / sleep deprecated."
